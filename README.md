# Коллективный блог

[![hexlet-check](https://github.com/mikitasazan/rails-project-64/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/mikitasazan/rails-project-64/actions)

Аналог habr.com. Каждый пользователь может создать запись и опубликовать ее в одной из общих категорий. Другие пользователи ставят оценки и комментируют добавленные посты.

Учебный проект Хекслета: https://ru.hexlet.io/programs/rails
Как это должно работать: https://files.hexlet.app/a/z5ld9a

## О Хекслете

[Хекслет](https://ru.hexlet.io/) — школа программирования: авторские программы обучения с практикой, поддержкой наставников и реальными проектами, которые остаются в резюме. Этот репозиторий — один из таких проектов.
